# Abraxas — Project Brief
*Last updated: 2026-03-25*

## What It Is
A gnostic-themed creative project. AI-generated skeleton entities walk through 7 Archon-controlled realms on their journey toward liberation/Abraxas. TikTok content engine + potential mobile app.

## Philosophical Foundation
See `source-text.md`. Core: Gnostic cosmology interpreted through Jung's depth psychology.
- 7 realms = 7 Archons (planetary rulers)
- Skeletons = wandering souls/divine sparks
- Journey = Gnostic ascent (gnosis → name Archons → integrate → liberation)
- Abraxas = supreme being above the Demiurge

## Content Pipeline
1. Define realm → visual style guide per Archon
2. Generate skeleton characters (AI image — Midjourney/Flux)
3. Animate through realm (video gen — Runway/Kling/Sora)
4. Narrate / score (voice + ambient)
5. Publish to TikTok
